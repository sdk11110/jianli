# 邵笛珂 · 叙事总站设计

**日期：** 2026-10-11  
**状态：** 用户已确认方向，进入视觉升级执行

## 目标

新建总站 `home/`，用 Born a Crime 式章节书脊呈现「完整的我」。现有作品集 `index/` 为 Ch.2 能力子集；云南手帐为 Ch.3 生活子集。

## 架构（方案 A：连续滚动舞台）

- 页面继续使用固定舞台 + 长滚动轨道，将每个节拍映射到人物姿态和信息卡。
- 首屏与章节之间保持同一镜头连续移动：人物始终是主视觉，卡片从左右错峰进入，背景色与颗粒氛围随章节渐变。
- 作品集和云南手帐使用 portal overlay 做圆形扩散转场，保留现有链接行为。
- 移动端保留人物与单列信息流，隐藏装饰性次级卡片，确保阅读和触控稳定。

## 视觉与动效

- 章间：米色纸张、细网格、手绘角色设定图和大号章节编号；深色段落切换为夜蓝与橙金光晕。
- 人物：使用用户提供的角色设定图作为首屏/章节背景纹理，并保留现有透明立绘做连续姿态前景。
- 动效：使用 transform/opacity/clip-path，入场 420–680ms，退出 160–260ms；滚动中人物有 3–5% 的尺度呼吸与 14px 内漂浮，减少跳切。
- 氛围：Three.js 粒子只承担轻微深度和指针跟随，不把信息藏在效果里。
- 可访问性：`prefers-reduced-motion` 下停用连续漂浮与转场，保持内容可见和链接可用。

## 体验验收

- 首屏 3 秒内能看出“人物向导 + 内容 AI 研发 / 项目负责人”的身份。
- 连续滚动 3 个节拍时，人物、背景和卡片无明显闪烁或布局跳动。
- 桌面端卡片与人物形成左右平衡，移动端单列不遮挡人物脸部与主要操作。
- 作品集、云南手帐、邮箱和外部链接都可用。

## 技术

- 静态 HTML / CSS / JS（与现作品集同栈习惯）
- Three.js（CDN）纸页/粒子氛围
- 本地静态服务预览
