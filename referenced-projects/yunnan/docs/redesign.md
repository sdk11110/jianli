# 云南手帐场景叙事改造

参考：https://hackthenorth.com/ ，2026-09-08 实际浏览当前版本。

用户方向：完整叙述风格与交互形式尽量贴近参考，视觉与交互以 95% 为目标，允许生成插画。

## 设计

保留原有三座城和八张照片的内容映射。沿用无构建步骤的 HTML/CSS/JS。
用青色山景、橙色木桌、纸张地图搭首屏，四个插画物件提供章节入口。
第二幕以红色唱机和错落唱片呈现开场；第三幕用草地、相机、明信片串联三座城，桌面滚动时保持场景并切换卡片，移动端自然排布。
第四幕用湖水颜色和照片筛选呈现记忆展厅；以纸质 FAQ 和手写信件收尾。
原始照片是内容，生成插画仅为装饰。音源为空时提供明确标识的合成环境音，不假装已有真实录音。

## 实施步骤

- 生成三组素材并保存至 assets/illustrations。
- 更新 index.html，新增独立 narrative.css / narrative.js，保留旧实现文件便于回看。
- 实现导航、三城滚动叙事、照片出片/翻面、展厅筛选/大图、FAQ、合成环境音。
- 验证原内容映射、浏览器桌面/窄屏布局与关键交互、无静态资源失败。

## 验收边界

95% 为用户的目标，不把主观观感当测量结果。实际交付记录差异：插画是重新生成的云南内容，文字/照片/页数不同，不声称像素级复刻。
