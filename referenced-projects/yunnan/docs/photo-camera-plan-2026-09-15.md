# 照片统一与相机出图

## 目标与设计

沿用云南手帐现有青绿、苔绿、奶油纸与油画棒插画风格。三张用户照片通过内置 image_gen 重绘，保留辨识构图，消除大疆水印，输出无文字、无边框的横幅画面。原始照片保留；网页消费压缩 WebP，PNG 留作高清素材。

相机以「准备 → 载入 → 出片 → 显影 → 可翻面」表达动作。快门即时反馈，出片约 720ms，显影约 460ms；锁定期间拦截重复提交。收起可以取消载入和动画，失败可重试且不跳过底片。减少动态效果时直接显示成片。计数来自实际数据，首轮优先展示新三张。

## 文件与实施顺序

- [x] assets/photos/painted：保存三张 PNG 与 WebP；记录生成提示词。
- [x] js/content.js：追加三张数据；用户确认三张均归入大理。
- [x] js/narrative.js：真实图替换占位、完整横图预览、大理展厅筛选、打开相机照片详情。
- [x] js/instant-camera.js：隔离相机生命周期、图像加载与动作取消逻辑。
- [x] css/photo-experience.css：统一画框、出片遮罩与显影、翻面、桌面/手机布局。
- [x] index.html：加载新模块与样式，更新底片描述。

## 验收清单

1. 三张图：彩虹、索道、日落均与原构图对应；无大疆字样；统一笔触与配色。
2. 图片与展厅：11 张均成功加载；新图优先；筛选、详情、左右键、关闭/焦点恢复。
3. 相机：快门按钮/机身均可出图；过程中不连跳；显影结束才能翻面；最后一张提示重新翻阅。
4. 中断：载入中/出片中收起，旧任务不能复活；失败保留游标，重试成功。
5. 响应式：1440/900/390/320px 相纸无裁切和横向滚动（列表统一 4:3 缩略图，详情显示完整横图），触控目标至少 44px。
6. 无障碍：键盘可触发、实时提示、隐藏背面语义、减少动态效果时无等待动画。
7. node --test tests/*.test.mjs 与浏览器实际点击检查；截图保存 output/qa。
