# 引用项目交付包

本包按2026-10-25本地实际文件整理，排除主首页 home，包含其链接的作品集及下属案例、云南手帐。
保留 index/ 和 yunnan/ 的原始相对目录，媒体文件原样保留，未重新编码。

## 打开方式
解压后双击“启动预览.bat”（需要 Python 3），打开 http://127.0.0.1:8878/index/ 。
也可在本目录运行 python preview.py --port 8878 。
云南手帐入口：http://127.0.0.1:8878/yunnan/ 。
各子项目的具体入口和引用关系见“项目清单.csv”。

## 范围说明
- 作品集、四类工作案例、培训 H5、项目交付页及云南手帐均包含当前本地页面、脚本、样式和媒体。
- 数学情景视频及教材项目附属的平均数互动演示一并保留。
- 云南手帐原来是本地目录联接，本包已写入真实文件，不依赖原机器路径。
- 返回“总站”的链接指向已按要求排除的 ../home/；如需恢复该入口，把原 home 文件夹放在 index、yunnan 同级即可。
- 保留当前项目的外部链接和在线字体请求；外部网站与后端服务不在本地包内。部分字体/外链功能需要联网。
- 已排除开发缓存、备份、Git 历史及未引用的 watch-word-reference 原始素材库。
- 这是当前本地静态版本；其中既有编译后的培训演示保留现状，不宣称包含未提供的原始框架工程。

## 校验
manifest.json 记录每个原有项目文件的大小和 SHA256；压缩包生成后已逐项读取验证。
