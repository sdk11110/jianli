## 运行
在本目录运行：`python -B scripts/preview.py --port 8877`，打开 http://127.0.0.1:8877/ 。
服务器映射 /home/、/index/ 与 /yunnan/。默认优先读取本项目 referenced-projects/index 和 referenced-projects/yunnan，来自用户提供的 referenced-projects-20261025.zip；不再依赖外部作品文件夹。显式 --root、--portfolio、--travel 配置仍优先，网页继续使用同源相对链接。
不需要安装前端依赖。请使用 HTTP 预览，ES modules 不依赖 file:// 运行。

## 行为
首屏入场仅一次，无自动循环；精细指针视差幅度受限，离屏不持续计算，减少动态立即静态。
标题默认可读，字体就绪后播放一次。鼠标经过「AI」仅轻摆该字块，点击、Enter或空格重播标题；连续触发取消上一段，不排队。标题离屏、页面隐藏或开启减少动态时立即恢复完整终态，无空转计时循环。
视频默认开启声音；首屏在小羊布展开场结束后尝试播放，浏览器限制有声自动播放时显示明确的一键播放入口。点击放大后直接尝试有声播放；同一时间只播放一个，离屏或文档隐藏暂停，返回不会自动续播。
手机和桌面均使用自定义放映组件，含播放、暂停、进度、声音和放大控件；视频不再显示浏览器原生控制条。放大保留原生对话框的 Esc 与焦点管理，界面和动效由本站设计。缓冲时显示小羊放映状态，加载失败可重试。
方法区支持点击、方向键、Home/End；四步始终说明哪些部分是检查思路示意。
首页和阅读页均同时展示三幅完整漫画。六章共18幅原画全部保留；章节按钮和左右方向键切换章节。点击单幅进入纸页阅读台，原画从所点位置连续展开，显示完整画面与对白；左右翻格，Esc收起并归还焦点。图片失败有重试，最后一章可返回首页手记。
页尾角色首次进入轻拉一次；悬停、点击、触摸或键盘可触发抓线回弹。动作在820–1050ms内收束，重复触发替换而不排队；减少动态、角色离屏或文档隐藏立即归位。
手机菜单与复制失败说明可用；邮件及全部既有作品入口保留。
